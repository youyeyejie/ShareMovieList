# 片刻放映室

把想一起看的电影、剧集和番剧钉在照片墙上，看完后收进相册。[打开观影清单](https://youyeyejie.github.io/ShareMovieList/)

**浏览片单**无需登录。在软木板顶部选择清单，按类型筛选或搜索作品。点击照片可看详情，复制当前网址即可分享这份片单。

**一起维护片单**需要 GitHub 账号拥有此仓库的写入权限。

1. 打开「连接设置」，填入自己的 GitHub 细粒度个人访问令牌，点击「验证 GitHub 身份」。创建令牌时，选择此仓库并授予 **Contents → Read and write** 权限。
2. 选择已有清单，或在清单菜单中点击「创建清单」。点击「添加作品」后，可以手动填写资料，也可以选择以下方式导入：
   - **查询 TMDB**：先在「连接设置」保存自己的 TMDB API Read Access Token，再输入片名并选择匹配结果。
   - **从豆瓣页面读取**：在浏览器中把豆瓣作品详情页保存为 HTML，选择该文件即可将资料填入草稿。
3. 核对资料后点击「保存并提交」，作品会显示在照片墙上，并在后台同步到 GitHub。之后可点开作品编辑，或点击「看过了」将它收进已看相册。

**本地预览**：在项目目录运行 `npm run dev`（需要 npm 和 Python 3），然后打开[本地放映室](http://127.0.0.1:5173/)。本地页面也连接同一仓库，保存会同步到共享片单。
