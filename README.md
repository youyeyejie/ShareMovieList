# 等空一起看

把想一起看的电影、剧集和番剧钉在片单墙上，看完后收进相册。[打开观影清单](https://youyeyejie.github.io/ShareMovieList/)

**浏览片单**无需登录。在软木板顶部选择清单，按类型筛选或搜索作品。点击照片可看详情，复制当前网址即可分享这份片单。

**一起维护片单**需要 GitHub 账号拥有此仓库的写入权限。

1. 打开「连接设置」，填入自己的 GitHub 细粒度个人访问令牌，点击「验证 GitHub 身份」。创建令牌时，选择此仓库并授予 **Contents → Read and write** 权限。
2. 选择已有清单，或在清单菜单中点击「创建清单」。点击「添加作品」后，可以手动填写资料，也可以选择以下方式导入：
   - **查询 TMDB**：先在「连接设置」保存自己的 TMDB API Read Access Token，再输入片名并选择匹配结果。
3. 核对资料后点击「保存并提交」，作品会显示在片单墙上，并在后台同步到 GitHub。之后可点开作品编辑，或点击「收进相册」将它收进「一起看过」。

**从豆瓣一键导入**：下载[浏览器扩展 ZIP](https://youyeyejie.github.io/ShareMovieList/downloads/douban-import.zip)并解压。在 Chrome 或 Edge 的扩展管理页开启「开发者模式」，点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的目录。

打开豆瓣电影或剧集的详情页，点击扩展图标 →「导入到片单」。在打开的片单页验证 GitHub 身份、选择目标清单，打开「添加作品」，再点击片名右侧的「从扩展读取」。核对后保存，封面图片与影片 JSON 会一起提交到仓库。封面原图不可读取时，扩展会尝试截取当前页完整可见的海报；也可以在编辑器中选择本地 JPG、PNG 或 WebP 图片（最大 4 MB）。草稿有效期为 15 分钟。

**本地预览**：在项目目录运行 `npm run dev`（需要 npm 和 Python 3），然后打开[本地预览](http://127.0.0.1:5173/)。本地页面也连接同一仓库，保存会同步到共享片单。
